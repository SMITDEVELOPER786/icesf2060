# ISRC-STM 2026 Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static-friendly Next.js App Router site for ISRC-STM 2026 (DHA Suffa University, IEEE affiliation line, six public pages, content in `content/site.ts`).

**Architecture:** React Server Components for pages; small client islands only for the mobile menu. All copy, dates, people, fees, and URLs come from `content/site.ts`. No backend, CMS, or on-site forms. Visual system is CSS variables (navy/cream/gold) plus Source Serif 4 and IBM Plex Sans — no Tailwind, no gradient meshes, no glass cards.

**Tech Stack:** Next.js (App Router) + React + TypeScript, next/font/google, Vitest + Testing Library, deploy on Vercel.

## Global Constraints

- Short name is **ISRC-STM 2026**. Do not use 2027 anywhere in branding or copy.
- Affiliation line is exactly ****. Do not invent IEEE Karachi Section, Computer Society, or unofficial IEEE logo artwork.
- Do not invent committee names, speaker names, or outbound URLs. Empty arrays and `null` links are valid.
- Colors: ink navy `#0B1F3A`, paper cream `#F4F0E8`, gold `#C4A574` (accent only, never body text on cream).
- Gold is not used as large fills. Card radius max 4px. No drop shadows. No mesh gradients. No glassmorphism. No Inter-only UI.
- Dates: Abstract 30 September 2026; Notification 10 October 2026; Full paper 30 October 2026; Conference 9–10 December 2026.
- Outbound CTAs: `target="_blank"` `rel="noopener noreferrer"`. Null href → disabled control labeled “Link to be announced”, not a dead `<a>`.
- Keep `docs/superpowers/` intact; this folder already has specs. Do not delete it when scaffolding.
- v1 has exactly these routes: `/`, `/call-for-papers`, `/committee`, `/speakers`, `/registration`, `/contact`.

import type { CommitteeSection, ImportantDate, Person } from "@/content/types";

export const COMMITTEE_SECTIONS: { id: CommitteeSection; heading: string }[] = [
  { id: "patron", heading: "Patron" },
  { id: "chair", heading: "Chair" },
  { id: "co-chair", heading: "Co-Chair" },
  { id: "secretary", heading: "Secretaries" },
  { id: "program", heading: "Program Committee" },
  { id: "review", heading: "Review Committee" },
  { id: "organizing", heading: "Organizing Committee" },
];

export function hasAnnouncement(value: string | null): boolean {
  return Boolean(value && value.trim().length > 0);
}

export function pageTitle(
  pageName: string | null,
  defaultTitle: string,
  titleTemplate: string,
): string {
  if (!pageName) return defaultTitle;
  return titleTemplate.replace("%s", pageName);
}

export function groupPeople(
  people: Person[],
): Record<CommitteeSection, Person[]> {
  const grouped: Record<CommitteeSection, Person[]> = {
    patron: [],
    chair: [],
    "co-chair": [],
    secretary: [],
    program: [],
    review: [],
    organizing: [],
  };
  for (const person of people) {
    grouped[person.section].push(person);
  }
  return grouped;
}

export function conferenceDatesLabel(
  dates: ImportantDate[],
): string | undefined {
  return dates.find((row) => row.id === "conference")?.date;
}

type CtaLinkProps = {
  href: string | null;
  children: React.ReactNode;
  className?: string;
};

export function CtaLink({ href, children, className }: CtaLinkProps) {
  if (!href) {
    return (
      <button type="button" className={className} disabled>
        Link to be announced
      </button>
    );
  }

  return (
    <a
      className={className}
      href={href}
      target="_blank"
      rel="noopener noreferrer"
    >
      {children}
    </a>
  );
}
